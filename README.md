# Voucher Hunter 1.0

Ứng dụng Android hỗ trợ cấu hình mục tiêu voucher, xem đồng hồ thiết bị độ chính xác hiển thị mili-giây, thử rung và mở Shopee.

## Build APK
Vào GitHub Actions, chọn workflow **Build Voucher Hunter APK**, chạy workflow và tải artifact **Voucher-Hunter-debug**.

## Giới hạn hiện tại
- Chưa tự nhận voucher, tự áp mã, tự checkout hoặc thanh toán.
- Không thu thập thông tin đăng nhập Shopee.
- Đồng hồ là giờ thiết bị, chưa xác thực giờ máy chủ.
- Cấu hình chưa được lưu bền vững qua lần mở app.
